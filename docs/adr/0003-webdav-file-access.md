# 3. Доступ к файлам точек через WebDAV

- Статус: черновик
- Дата: 2026-10-13

## Файлы

Сервер отдаёт файлы точек по WebDAV и возвращает любой диапазон байт файла.
Содержимое он не разбирает. Чтение меты и чтение точки — несколько частичных
чтений одного и того же файла.

## Мета и точка

`load_meta` и `load_point` собирают ответ на клиенте.

1. Клиент читает заголовок фиксированной длины.
2. Из заголовка берёт размер нужного куска и его смещение: мета для
   `load_meta`, данные для `load_point`.
3. Читает только этот диапазон и разбирает его.

Заголовок DF01 — 30 байт. Длина и раскладка заголовка известны клиенту.

## Свойства и список

Время изменения и прочие свойства файла клиент читает из WebDAV.
`load_modified_time` берёт их оттуда.

`FSRepr::ls` строится из листинга WebDAV.

## ROOT (в перспективе)

ROOT-скрипт открывает удалённый ROOT-файл, который лежит на этом сервере.

Для этого WebDAV отдаёт файл по обычному HTTP(S)-адресу, тело GET — байты
файла, и принимает частичное чтение (`Range`).
