# 3. Бинды пайплайна обработки на другие ЯП

- Статус: черновик
- Дата: 2026-10-15

## Схема биндингов
Изменяется модуль numass-processing.

Шаги обработки переносятся один в один из Rust: те же аргументы, тот же результат. Результат остаётся Rust-структурой. Отдельные биндинги полей промежуточных типов не пишутся; если доступ к полю появляется сам, это нормально. Промежуточные значения не копируются: вызывающий держит исходные данные, шаг получает ту же ссылку, что и в Rust.

У результата обработки есть метод `to_polars()`. Это одностороннее преобразование в таблицу Polars; как собрана таблица, не важно. После преобразования это уже таблица Polars, и методы обработки модуля на ней не вызываются.

Сценарий обработки: построить цепь предобработка → (обработка) → (постобработка) → `to_polars()` → дальнейший анализ на Python.
